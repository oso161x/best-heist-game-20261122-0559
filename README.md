**Midnight Vault** — a complete top-down stealth heist game that plays offline in a desktop browser from its own files. Cross the museum vault at night, dodge three patrolling guards with vision cones and two sweeping security cameras, grab the Star Diamond, the gold bars and the painting, watch the alarm meter, and escape through the green EXIT. Sneak with Shift, toss a coin with Q to distract a guard, disable the cameras from the blue CAM panel with E.

WASD / arrow keys move · Shift sneak · E grab / use panel · Q toss a coin · P pause · M mute. Title, play, pause, win and caught screens, best score kept in the browser, synthesized WebAudio bleeps (no audio files).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the game loads from game/index.html with no network request.
